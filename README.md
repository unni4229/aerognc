# AeroGNC

## Autonomous Fixed-Wing UAV Guidance, Navigation and Control Framework

A modular fixed-wing UAV simulation and GNC development project.

The project will progressively integrate:

- 6-DOF nonlinear aircraft dynamics
- Aerodynamic modelling
- Propulsion modelling
- Aircraft trim analysis
- Guidance and path following
- INS/GPS Extended Kalman Filter
- PID control
- Model Predictive Control
- Sensor and actuator fault detection
- FlightGear simulation
- ArduPilot SITL
- MAVLink communication
- Mission Planner

## Current Development Stage

### Level 1A — Aircraft Plant

Current focus:

- Aircraft parameters
- Coordinate systems
- 6-DOF equations of motion
- Aerodynamics
- Propulsion
- Numerical integration
- Plant validation

## Technology

Python, NumPy, SciPy, Matplotlib, Pandas, PyYAML and Pytest.
